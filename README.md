## Описание проекта

«Астероиды» — двумерная аркада, в которой игрок управляет кораблём и
уничтожает астероиды ракетами. Корабль, астероиды и ракеты переходят
через границы поля, продолжая движение с противоположной стороны.

## Функциональные возможности

### Основной функционал

- Полупрозрачная заставка с запуском партии по щелчку и движущимся слоем
  полупрозрачных астероидов поверх неподвижной космической туманности.
- Управление поворотом и тягой корабля, смена изображения двигателя
  и постепенное торможение после отключения тяги.
- Астероиды влетают с разных сторон экрана с разными скоростями и
  вращением.
- Ракеты с ограниченным временем полёта и один балл за каждое попадание.
- Тайловая анимация взрыва и возрождение корабля в центре поля.
- Итоговый счёт на заставке и запуск новой партии из того же окна.

## Требования к системе

- Python 3.9 или новее с модулем `tkinter` и поддержкой PNG в Tk.
- Windows, macOS или Linux с графической средой.
- Сторонние библиотеки отсутствуют. В Linux модуль `tkinter` может
  поставляться отдельным системным пакетом, например `python3-tk`.

## Установка и запуск

### 1. Получите файлы проекта

Распакуйте архив и откройте терминал в каталоге `asteroids`.
При получении проекта из публичного GitHub-репозитория скопируйте его
HTTPS-адрес через **Code → HTTPS**. Выполните команды, заменив значения
в кавычках адресом и именем каталога репозитория.

```text
git clone "HTTPS-адрес репозитория"
cd "имя репозитория"
```

### 2. Создайте и активируйте виртуальное окружение

Пересоздайте `venv` для установленного у вас Python. Если используете
Python 3.13 или новее, добавьте параметр `--without-scm-ignore-files`
к команде создания окружения, чтобы Git видел содержимое `venv/`.

Windows PowerShell

```powershell
python -m venv --clear venv
.\venv\Scripts\Activate.ps1
```

Windows cmd

```bat
python -m venv --clear venv
venv\Scripts\activate.bat
```

macOS и Linux

```bash
python3 -m venv --clear venv
source venv/bin/activate
```

### 3. Установите зависимости

```text
python -m pip install -r requirements.txt
```

### 4. Запустите игру

```text
python main.py
```

Если PowerShell блокирует активацию скриптов, игру можно запустить из
созданного окружения командой `.\venv\Scripts\python.exe main.py`.

### 5. Управление

| Действие | Управление |
| --- | --- |
| Начать партию | Щёлкнуть левой кнопкой мыши внутри заставки |
| Повернуть корабль | Стрелки влево и вправо |
| Включить тягу | Удерживать стрелку вверх |
| Выпустить ракету | Нажать пробел |

## Структура проекта

```text
asteroids/
├── .gitignore
├── README.md
├── requirements.txt
├── main.py
├── model.py
├── settings.py
├── view.py
├── assets/
│   ├── asteroids.png
│   └── nebula.png
└── venv/
```

| Файл | Назначение |
| --- | --- |
| `main.py` | Точка входа, обработчики событий и цикл приложения |
| `model.py` | Состояние партии, движение и столкновения без привязки к Tk |
| `settings.py` | Параметры поля, физики, управления и анимации |
| `view.py` | Слои фона, отрисовка объектов и таблица кадров взрыва |
| `assets/` | Звёздный фон и атлас кадров астероидов |
| `venv/` | Виртуальное окружение Python |

Разделение модели и отрисовки позволяет проверять механику без открытия
окна. Изменения внешнего вида сосредоточены в модуле отрисовки,
а параметры игрового процесса и анимации собраны в одном месте.

## Пример использования

1. Выполните `python main.py`. На заставке отображаются 3 жизни и 0 очков.
2. Нажмите **Начать игру**, поверните корабль к астероиду и нажмите пробел.
3. При попадании появится взрыв, а счёт увеличится на 1.
4. При столкновении корабль возрождается в центре и расходует одну
   запасную жизнь. Столкновение при нуле запасных жизней завершает партию.
5. На заставке останется итоговый счёт. Нажмите **Играть снова** для
   начала новой партии с 3 жизнями и нулевым счётом.
